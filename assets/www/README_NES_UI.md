# NES Runner UI (from APK design)

تصميم واجهة المحاكي المستخرج من حزمة NOR Maker APK:

| ملف | الدور |
|------|--------|
| `nes-runner.html` | هيكل الشاشة (D-Pad / SELECT-START / A-B / 4:3) |
| `runner-emu-ref.css` | التنسيق الأساسي (أسود + سماوي نيون) |
| `runner-landscape-nes.css` | لمسات landscape إضافية |

**المصدر:** `wnv7b2.apk` → `assets/www/runner-emu-ref.css`

افتح `nes-runner.html` في المتصفح أو اربطه بـ WebView / native canvas (`#gameCanvas`).
