**الخلاصة الفنية لملفات الـ DLL والـ EXE:**
- جميع ملفات الـ DLL (`gm82save.dll`, `libeay32.dll`) والـ EXE في حزمة Portable الأصلية مبنية لمعمارية **x86 (32-bit)** فقط.
- مشغل ومحرك NOR Windows مبني كـ **x64 (64-bit)** لتحقيق الأداء الأمثل واستيعاب الذاكرة الكبيرة.
- دمج ملفات DLL الـ 32-bit مباشرة داخل تطبيق 64-bit كان سيؤدي فوراً إلى انهيار التطبيق (`STATUS_INVALID_IMAGE_FORMAT` / 0xC000007B).
- تم اتخاذ القرار الهندسي السليم: استخلاص تعريفات الدوال ومكتبات الـ DnD كبيانات وتضمين بدائل أصلية لمهام الصوت والـ I/O بدلاً من استيراد الـ DLLs العتيقة مباشرة.

## 3. اختبارات الأداء والتوافق (Performance & Parity Benchmarks)

- **مجموعة الاختبارات الشاملة (Full Engine Test Suite):** نجحت بالكامل (`SUITE_EXIT=0`).
- **محاكاة وفيزياء ألعاب العينات (4-Game Pipeline):**
  - Mario Bros: فك الموارد وتشغيل 30 إطاراً واختبار الحفظ والاسترجاع (نجاح).
  - Plataformas: فك 42 سبرايت و 4 غرف وتشغيل 30 إطاراً (نجاح).
  - Shooter: فك 308 كائن ومحاكاة 30 إطاراً (نجاح).
  - Zelda: فك 49 سبرايت و 3 غرف ومحاكاة 30 إطاراً (نجاح).
- **زمن تشغيل خط محاكاة الألعاب الأربع كاملاً:** `10.154` ثانية.
- **حالة الأداء:** استقرار تام، استهلاك ذاكرة منضبط، ومطابقة بيكسلية تامة لحركة الكائنات.

## 4. التحسينات المنجزة لنسخة Windows

1. **إخراج الصوت الأصلي (Native Audio Backend):** تم دمج مُخرِج صوتي نقي يعمل عبر Windows `waveOut` لضمان تشغيل الأصوات دون الحاجة إلى مكتبات خارجية غير متوافقة.
2. **دعم مسارات اليونيكود (Unicode / UTF-8):** دعم فتح وسحب وإفلات المشاريع ذات المسارات والأسماء العربية والرموز الخاصة.
3. **حماية دورة الحياة والمفاتيح العالقة (Lifecycle & Input Safety):** منع تعليق أزرار الحركة أو القفز عند فقدان تركيز النافذة (`WM_KILLFOCUS` / `WM_ACTIVATEAPP`).
4. **أداة التغليف القابلة للتكرار (Packaging Tool):** تم توفير سكربت `package_portable.sh` لإنتاج الحزمة الكاملة مع الحفاظ على البصمات.
5. **التكامل المستمر (GitHub CI):** تم تفعيل سير عمل آلي `.github/workflows/windows-build.yml` للتحقق المستمر وبناء نسخة Windows x64 آلياً.
