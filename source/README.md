# GM82 source mirror

هذا المجلد هو مرآة المصادر التي تم الوصول إليها لمشروع GM82/NM Maker.

## التنظيم

- `*.zip`: أرشيفات المصدر الأصلية كما تم الحصول عليها من مستودعات GM82.
- `unpacked/`: نسخ مفكوكة من الأرشيفات نفسها، محفوظة بأسماء المشاريع لتسهيل البحث والبناء والمقارنة.
